DoorLoop Product Tours

Proof of concept: guided tours that run on top of DoorLoop without changing its code. Open a tour's link and it goes to the right page and starts.

One-time setup

  1. Download the DoorLoop Tours extension and unzip it.
  2. In Chrome, open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and select the unzipped folder.
  4. Log in to DoorLoop in the same browser, then open a tour below.

On any DoorLoop page that has tours, a Tours button appears in the bottom-right corner. New and edited tours show up automatically; you only reinstall when the extension itself changes. To build a new tour, click the extension's icon on any DoorLoop page, then Build a new tour here.

Live tours

Everyone with the extension sees these. Hover over a tour (or tab to it) for its link. Edit opens it in the builder on DoorLoop; saving it there updates the live tour for everyone.

Drafts

Tours that aren't live yet. Only people who turn on Show drafts see them on DoorLoop, in that browser: turn on · turn off. Preview runs a draft and turns Show drafts on; Copy copies its permanent link, to share once it's live.

To make a draft live, click Approve (it opens the tour's file on GitHub), change "status": "draft" to "status": "live", and commit; or click Edit and set Status to Live under ⋯ More before saving. It goes live for everyone once published.

Deleting a tour

Delete on a card opens GitHub's Delete file page for that tour; click Commit changes there and it's gone from this page and from DoorLoop a minute later. Deleting a live tour breaks links already shared for it, so if someone might still use it, switch it back to a draft instead (Edit, then Status under ⋯ More). GitHub keeps the file's history, so a deleted tour can be brought back.
