DoorLoop Product Tours

Proof of concept: guided tours that run on top of DoorLoop without changing its code. Pick a tour and it opens the right page in DoorLoop and starts.

One-time setup

  1. Download the DoorLoop Tours extension and unzip it.
  2. In Chrome, open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and select the unzipped folder.
  4. Log in to DoorLoop in the same browser, then click a tour above.

New and edited tours show up automatically; you only reinstall when the extension itself changes.
