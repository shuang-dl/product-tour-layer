DoorLoop Product Tours

Proof of concept: guided tours that run on top of DoorLoop without changing its code. Pick a tour and it opens the right page in DoorLoop and starts.

Loading tours…

One-time setup

  1. Install the Tampermonkey browser extension.
  2. Install the tour layer script and click Install in the Tampermonkey tab that opens.
  3. Log in to DoorLoop in the same browser, then click a tour above.

On any DoorLoop page that has tours, a Tours button appears in the bottom-right corner.
